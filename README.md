# قیمت‌یاب صوتی خودرو

نام و مدل ماشین را **با صدا** بگویید (یا تایپ کنید)؛ برنامه قیمت حدودی امروز را از چند سایت ایرانی جمع می‌کند و یک برآورد واحد می‌دهد.

- **باما** (bama.ir): قیمت روز خودروی صفر (بازار و کارخانه) + آگهی‌های فروش
- **دیوار** (divar.ir): آگهی‌های فروش خودرو در شهرهای بزرگ (یا شهر انتخابی)
- **همراه مکانیک** (hamrah-mechanic.com): قیمت بازار هر تیپ به تفکیک سال ساخت

نمونه‌هایی که می‌توانید بگویید:

| گفته | برداشت برنامه |
|---|---|
| «قیمت پژو دویست و شش تیپ دو مدل نود و هشت چنده؟» | پژو 206 تیپ 2، سال 1398 |
| «پراید صد و سی و یک مدل ۹۸» | پراید 131، سال 1398 |
| «سمند ال ایکس مدل چهارصد و دو» | سمند LX، سال 1402 |
| «پژو چهارصد و پنج جی ال ایکس کارکرده» | پژو 405 GLX، فقط کارکرده |
| «دنا پلاس صفر» | دنا پلاس، فقط صفر کیلومتر |
| «تویوتا کمری ۲۰۱۸» | تویوتا کمری، سال میلادی 2018 |

## نتیجه چطور حساب می‌شود؟

1. جمله به «نام خودرو»، «سال ساخت» و «صفر/کارکرده» تجزیه می‌شود (عدد نوشتاری مثل «دویست و شش» به 206 تبدیل می‌شود؛ «مدل ۹۸» یعنی ۱۳۹۸ و «مدل ۴۰۲» یعنی ۱۴۰۲).
2. نام خودرو در فهرست مدل‌های هر سایت پیدا می‌شود (تطبیق تقریبی برای کلمه‌ها، دقیق برای عددها؛ پس 206 با 207 یا 2008 اشتباه نمی‌شود).
3. قیمت‌ها به گروه «صفر کیلومتر» و «سال ساخت» تقسیم می‌شوند، آگهی‌های پرت (مثلاً قیمت اشتباه تایپ‌شده) با روش IQR کنار می‌روند و میانهٔ هر سایت حساب می‌شود.
4. **قیمت حدودی** = میانهٔ میانه‌های سایت‌ها. بازهٔ نمایش‌داده‌شده، کمترین و بیشترین میانهٔ سایت‌هاست.
5. **قیمت کارخانه** (مصوب) جدا نمایش داده می‌شود و در برآورد حساب نمی‌شود، چون با قیمت بازار فاصلهٔ زیادی دارد. آگهی‌های اقساطی، توافقی و حواله هم در برآورد نیستند.

> قیمت آگهی‌ها پیشنهادی فروشنده است، نه قیمت نهایی معامله؛ نتیجه را تقریبی بدانید.

## اجرا

نیاز: **Node.js نسخهٔ ۱۸.۱۷ یا بالاتر**. هیچ وابستگی (npm install) لازم نیست.

```bash
npm start
```

سپس `http://localhost:3000` را در **کروم** یا **اج** باز کنید.

### بررسی دسترسی به سایت‌ها

```bash
npm run diagnose
```

خروجی نشان می‌دهد سرور به هر سایت دسترسی دارد یا نه. همین بررسی در آدرس `/api/diagnose` هم هست.

### حالت نمایشی (بدون اینترنت)

```bash
npm run demo
```

با داده‌های نمونه (فقط «پژو ۲۰۶» و «پراید ۱۳۱»)، برای دیدن ظاهر برنامه روی هر سیستمی. قیمت‌ها واقعی نیستند.

### آزمون‌ها

```bash
npm test
```

## نکته‌های مهم برای راه‌اندازی

- **سرور باید در ایران باشد.** باما، دیوار و همراه مکانیک درخواست‌های IP خارج از ایران را رد می‌کنند (اتصال قطع می‌شود). روی سرور خارجی، صفحه بالا می‌آید ولی هر سه منبع خطا می‌دهند.
- **میکروفون فقط با HTTPS کار می‌کند** (به‌جز `localhost`). روی سرور، یک دامنه با گواهی SSL لازم است. ساده‌ترین راه، [Caddy](https://caddyserver.com) است که گواهی را خودش می‌گیرد:

  ```
  car.example.ir {
      reverse_proxy localhost:3000
  }
  ```

  با nginx هم می‌شود (`proxy_pass http://127.0.0.1:3000;` و certbot). پشت پراکسی، `TRUST_PROXY=1` بگذارید تا محدودیت درخواست براساس IP واقعی کاربر باشد.
- **تشخیص گفتار مرورگر:** کروم و اج صدا را برای تبدیل به متن به سرویس گوگل می‌فرستند. اگر این سرویس از ایران در دسترس نباشد، برنامه پیام «سرویس تشخیص گفتار در دسترس نیست» می‌دهد و کاربر می‌تواند تایپ کند. سافاری و فایرفاکس فارسی را به‌خوبی پشتیبانی نمی‌کنند.
- **ساختار سایت‌ها ممکن است عوض شود.** کد هر سایت در یک فایل جداست (`src/sources/`). اگر `npm run diagnose` برای یک سایت خطا داد، فقط همان فایل باید به‌روز شود؛ دو سایت دیگر کار می‌کنند.

### اجرای دائمی با systemd (نمونه)

```ini
# /etc/systemd/system/gheymat.service
[Unit]
Description=Gheymat Khodro
After=network.target

[Service]
WorkingDirectory=/opt/gheymat-khodro
ExecStart=/usr/bin/node server.js
Environment=PORT=3000 TRUST_PROXY=1
Restart=always
User=www-data

[Install]
WantedBy=multi-user.target
```

```bash
sudo systemctl enable --now gheymat
```

### متغیرهای محیطی

| متغیر | پیش‌فرض | توضیح |
|---|---|---|
| `PORT` | `3000` | پورت سرور |
| `HOST` | `0.0.0.0` | نشانی گوش‌دادن |
| `DEMO` | — | `1` = حالت نمایشی با داده‌های نمونه |
| `RATE_LIMIT` | `20` | حداکثر جستجو در دقیقه برای هر IP |
| `TRUST_PROXY` | — | `1` = خواندن IP کاربر از `X-Forwarded-For` (پشت nginx/Caddy) |

## API

`GET /api/price?q=<جملهٔ کاربر>&city=all|1|2,...`

- `query`: برداشت از جمله (`carText`، `year`، `condition`)
- `summary`: برآورد اصلی (`estimate`، `low`، `high`، و سهم هر سایت)
- `newCar`: برآورد صفر کیلومتر؛ `byYear`: برآورد هر سال ساخت؛ `factory`: قیمت‌های کارخانه
- `sources`: نتیجهٔ خام هر سایت (موفق/ناموفق، خطا، مدل پیداشده، آگهی‌ها و فهرست قیمت با لینک)

کدهای شهر دیوار: ۱ تهران، ۲ کرج، ۳ مشهد، ۴ اصفهان، ۵ تبریز، ۶ شیراز، … (پیش‌فرض: این شش شهر).

## ساختار پروژه

```
server.js              سرور HTTP (صفحه + API)
src/text.js            یکسان‌سازی فارسی، عدد نوشتاری، سال، قیمت و کارکرد
src/match.js           تطبیق تقریبی نام خودرو
src/http.js            کلاینت HTTP با کش، مهلت، تلاش دوباره و محدودیت هم‌زمانی
src/sources/bama.js    باما
src/sources/divar.js   دیوار
src/sources/hamrah.js  همراه مکانیک
src/aggregate.js       آمار، حذف داده‌های پرت و برآورد نهایی
src/lookup.js          اجرای هم‌زمان سه منبع
src/demo.js            fetch جعلی برای حالت نمایشی و آزمون‌ها
public/                رابط کاربری (فارسی، راست‌به‌چپ، حالت تیره)
test/                  آزمون‌ها و داده‌های نمونه
```

فونت [وزیرمتن](https://github.com/rastikerdar/vazirmatn) داخل پروژه است (مجوز OFL در `public/fonts/OFL.txt`) تا به Google Fonts وابسته نباشد.
