# قیمت‌یاب صوتی خودرو

نام و مدل ماشین را **با صدا** بگویید (یا تایپ کنید)؛ برنامه قیمت حدودی امروز را از چند سایت ایرانی جمع می‌کند و یک برآورد واحد می‌دهد.

تشخیص گفتار فارسی **روی خود سرور** و با [whisper.cpp](https://github.com/ggml-org/whisper.cpp) انجام می‌شود (بدون گوگل و بدون فیلترشکن) و در همهٔ مرورگرها، از جمله سافاری آیفون، کار می‌کند.

- **باما** (bama.ir): قیمت روز خودروی صفر (بازار و کارخانه) + آگهی‌های فروش
- **دیوار** (divar.ir): آگهی‌های فروش خودرو در شهرهای بزرگ (یا شهر انتخابی)
- **همراه مکانیک** (hamrah-mechanic.com): قیمت بازار هر تیپ به تفکیک سال ساخت

نمونه‌هایی که می‌توانید بگویید:

| گفته | برداشت برنامه |
|---|---|
| «قیمت پژو دویست و شش تیپ دو مدل نود و هشت چنده؟» | پژو 206 تیپ 2، سال 1398 |
| «پراید صد و سی و یک مدل ۹۸» | پراید 131، سال 1398 |
| «سمند ال ایکس مدل چهارصد و دو» | سمند LX، سال 1402 |
| «پژو چهارصد و پنج جی ال ایکس کارکرده» | پژو 405 GLX، فقط کارکرده |
| «دنا پلاس صفر» | دنا پلاس، فقط صفر کیلومتر |
| «تویوتا کمری ۲۰۱۸» | تویوتا کمری، سال میلادی 2018 |

## نام ناقص

لازم نیست نام کامل را بگویید؛ برنامه نام کامل را از فهرست مدل‌های باما پیدا می‌کند و **هر سه سایت با همان نام کامل** جستجو می‌شوند، پس قیمت و بازه همان است که با نام کامل می‌گرفتید:

| گفته | برداشت |
|---|---|
| «۲۰۶ تیپ ۲ مدل ۱۴۰۰» | پژو 206 تیپ 2، 1400 |
| «سورن مدل ۹۹»، «سمند سورن ۹۹» | سمند سورن، 1399 |
| «سراتو ۲۰۱۵»، «سرا تو مدل دو هزار و پانزده» | کیا سراتو، 2015 |
| «۲۰۶ صندوقدار»، «دویست و شش اس دی» | پژو 206 SD |
| «پرشیا دوگانه سوز ۹۶» | پژو پارس دوگانه سوز، 1396 |
| «پراید ۹۸» (عدد آخر بدون «مدل») | پراید، 1398 |

- اگر فقط مدل گفته شود («۲۰۶»)، قیمت برای همهٔ تیپ‌هاست و دکمه‌های **«تیپ ۲»، «تیپ ۵»** برای دقیق‌تر کردن نشان داده می‌شود؛ مدل‌های مشابه هم در «شاید منظورتان…» می‌آیند («پژو ۲۰۶ SD»). آگهی‌های مدل دقیق‌تر (مثلاً ۲۰۶ SD) در قیمت ۲۰۶ معمولی حساب نمی‌شوند.
- اگر فقط برند گفته شود («پراید مدل ۹۸»)، قیمت با برچسب «همهٔ مدل‌های پراید» نشان داده می‌شود و می‌پرسد «کدام مدل؟». اگر برند فقط یک مدل داشته باشد، همان انتخاب می‌شود.
- اگر سال نامفهوم باشد («مدل نواتونان»)، خودرو پیدا می‌شود و برنامه می‌گوید سال را متوجه نشده است.
- اگر باما در دسترس نباشد، دیوار و همراه مکانیک خودشان نام را تطبیق می‌دهند.

## نتیجه چطور حساب می‌شود؟

1. جمله به «نام خودرو»، «سال ساخت» و «صفر/کارکرده» تجزیه می‌شود (عدد نوشتاری مثل «دویست و شش» به 206 تبدیل می‌شود؛ «مدل ۹۸» یعنی ۱۳۹۸ و «مدل ۴۰۲» یعنی ۱۴۰۲).
2. نام خودرو در فهرست مدل‌های هر سایت پیدا می‌شود (تطبیق تقریبی برای کلمه‌ها، دقیق برای عددها؛ پس 206 با 207 یا 2008 اشتباه نمی‌شود).
3. قیمت‌ها به گروه «صفر کیلومتر» و «سال ساخت» تقسیم می‌شوند، آگهی‌های پرت (مثلاً قیمت اشتباه تایپ‌شده) با روش IQR کنار می‌روند و میانهٔ هر سایت حساب می‌شود.
4. **قیمت حدودی** = میانهٔ میانه‌های سایت‌ها. بازهٔ نمایش‌داده‌شده، کمترین و بیشترین میانهٔ سایت‌هاست.
5. **قیمت کارخانه** (مصوب) جدا نمایش داده می‌شود و در برآورد حساب نمی‌شود، چون با قیمت بازار فاصلهٔ زیادی دارد. آگهی‌های اقساطی، توافقی و حواله هم در برآورد نیستند.

> قیمت آگهی‌ها پیشنهادی فروشنده است، نه قیمت نهایی معامله؛ نتیجه را تقریبی بدانید.

## استقرار روی لیارا (پیشنهادی)

[لیارا](https://liara.ir) سرور در ایران دارد (پس باما، دیوار و همراه مکانیک در دسترس‌اند)، HTTPS می‌دهد (برای میکروفون لازم است) و برنامه را از روی `Dockerfile` همین مخزن می‌سازد.

**ساخت فقط چند ثانیه طول می‌کشد** (سقف ساخت در پلن رایگان لیارا ۵ دقیقه است):

- **whisper از پیش ساخته شده:** `whisper-cli` در `vendor/whisper.cpp` است؛ منشأ، تنظیمات ساخت و checksumها در `vendor/whisper.cpp/README.md` آمده است.
- **مدل هنگام اولین اجرا دانلود می‌شود:** مدل تشخیص گفتار (۸۷۰ مگابایت) در پس‌زمینه دانلود و با sha256 بررسی می‌شود. تا آن موقع سایت کار می‌کند و تشخیص گفتار مرورگر استفاده می‌شود؛ بعد، تشخیص گفتار روی سرور خودکار فعال می‌شود. وضعیت دانلود در `/api/health` دیده می‌شود.

1. در پنل لیارا یک برنامه از نوع **Docker** بسازید. نام پیشنهادی `gheymat-khodro` است؛ اگر نام دیگری گذاشتید، مقدار `app` در `liara.json` را هم عوض کنید.
   - **حافظه:** برای تشخیص گفتار روی سرور، پلن با **دست‌کم ۱٫۵ گیگابایت حافظه** لازم است (whisper حدود ۱٫۱ گیگابایت می‌گیرد). با حافظهٔ کمتر، مدل دانلود نمی‌شود، تشخیص گفتار مرورگر استفاده می‌شود و بقیهٔ برنامه کامل کار می‌کند.
   - **پردازنده:** هرچه هسته بیشتر، تبدیل گفتار سریع‌تر.
2. **دیسک برای مدل (لازم برای تشخیص گفتار روی سرور):** مدل فقط وقتی دانلود می‌شود که دیسکی به پوشهٔ مدل وصل باشد؛ بدون دیسک، دانلود ۸۷۰ مگابایتی در فضای موقت کانتینر ممکن است از سقف پلن بگذرد و کانتینر را مدام از نو راه بیندازد. در پنل لیارا یک دیسک ۲ گیگابایتی به نام `whisper-models` بسازید و این را به `liara.json` اضافه کنید (بدون دیسک، برنامه کامل کار می‌کند و تشخیص گفتار مرورگر استفاده می‌شود):

   ```json
   "disks": [{ "name": "whisper-models", "mountTo": "/app/whisper/models" }]
   ```

3. استقرار، به یکی از دو روش:
   - **خودکار از گیت‌هاب:** در مخزن گیت‌هاب، Settings ← Secrets and variables ← Actions، یک Secret به نام `LIARA_API_TOKEN` با کلید API حساب لیارا بسازید. اگر نام برنامه با `liara.json` فرق دارد، یک Variable به نام `LIARA_APP_NAME` هم بسازید. از این پس با هر ادغام در `main`، آزمون‌ها اجرا و برنامه روی لیارا مستقر می‌شود (`.github/workflows/ci-deploy.yml`).
   - **دستی از کامپیوتر خودتان** (در پوشهٔ پروژه):

     ```bash
     npm install -g @liara/cli
     ```

     ```bash
     liara login
     ```

     ```bash
     liara deploy
     ```

4. بعد از استقرار:
   - `https://<نام-برنامه>.liara.run/api/diagnose`: هر سه سایت باید `"ok": true` و تعداد قیمت بیشتر از صفر داشته باشند.
   - `https://<نام-برنامه>.liara.run/api/health`: در بخش `stt`، وضعیت دانلود مدل (`download`) یا علت خاموش بودن تشخیص گفتار سرور (`reason`) آمده است.

نکته‌ها:

- **اگر مدل از سرور لیارا دانلود نشد** (مثلاً huggingface.co از ایران در دسترس نبود): فایل `ggml-large-v3-turbo-q8_0.bin` را جای دیگری دانلود کنید و در فضای ذخیره‌سازی ابری لیارا (Object Storage) بگذارید، سپس نشانی آن را در متغیر محیطی `WHISPER_MODEL_URL` بدهید. checksum همچنان بررسی می‌شود.
- **سرعت تشخیص گفتار:** whisper.cpp برای همهٔ نسل‌های پردازنده ساخته شده و هنگام اجرا بهترین را برای پردازندهٔ همان سرور انتخاب می‌کند. در آزمایش داخل Docker با ۴ هسته:
  - پردازندهٔ دارای AMX (Xeon نسل ۴ به بعد): حدود **۲ تا ۳ ثانیه** برای هر جمله.
  - بدون AMX (فقط AVX-512 یا AVX2): حدود **۶ ثانیه**.
  - با ۲ هسته تقریباً دو برابر.
- **خطای 502:** یعنی مسیریاب لیارا به برنامه نرسیده است. برنامه روی پورت ۳۰۰۰ و برای اطمینان روی ۸۰ و ۸۰۸۰ هم گوش می‌دهد، روی همهٔ نشانی‌ها (IPv4 و IPv6). در لاگ‌های برنامه (پنل لیارا، بخش لاگ‌ها):
  - خط «قیمت‌یاب خودرو آماده است» یعنی برنامه بالا آمده است.
  - خط «نشانی‌های شبکهٔ کانتینر» نشانی‌های کانتینر را نشان می‌دهد و اینکه IPv6 دارد یا نه.
  - خط «اتصال رسید: پورت …، از …» یعنی کسی به آن پورت وصل شده است (حتی اگر درخواست درستی نفرستاده باشد).
  - خط «درخواست رسید: … (پورت …، از …)» یعنی درخواست HTTP درستی رسیده است؛ پورت و فرستنده‌اش را هم نشان می‌دهد.
  - خط «درخواست نامعتبر روی پورت …؛ آغاز داده: …» یعنی چیزی جز HTTP ساده رسیده است؛ مثلاً `\u0016\u0003` یعنی HTTPS، `PROXY TCP4` یعنی PROXY protocol و `PRI * HTTP/2.0` یعنی HTTP/2.
  - از هر کدام ده مورد اول ثبت می‌شود.
  - اگر برنامه بالا آمده ولی هیچ «اتصال رسید» نیامده، لیارا ترافیک را به برنامه نمی‌فرستد: صفحهٔ «رویدادها» (Events) برنامه را ببینید، پورت برنامه در تنظیمات لیارا را با `port` در `liara.json` (۳۰۰۰) یکی کنید، یا با `liara deploy` از پوشهٔ پروژه مستقر کنید تا `liara.json` خوانده شود.
- **اگر whisper روی پردازندهٔ سرور اجرا نشود:** تشخیص گفتار سرور خودکار خاموش می‌شود و صفحه از تشخیص گفتار مرورگر استفاده می‌کند (جستجوی متنی همیشه کار می‌کند).
- **بدون تشخیص گفتار سرور:** متغیر محیطی `WHISPER_MODEL_NAME=none` را بگذارید.
- **محدودیت Docker Hub:** اگر ساخت با خطای 429 از Docker Hub متوقف شد، در `Dockerfile` مقدار `BASE_REGISTRY` را `mirror.gcr.io/library/` بگذارید.
- **محل ساخت:** ساخت روی سرور آلمانِ لیارا است (`build.location` در `liara.json`). اگر پلن شما این را اجازه نمی‌دهد، آن خط را بردارید؛ ساخت دیگر چیزی از اینترنت دانلود نمی‌کند.
- **حالت نمایشی روی لیارا:** متغیر محیطی `DEMO=1` را در پنل لیارا تعریف کنید.

## اجرا

نیاز: **Node.js نسخهٔ ۱۸.۱۷ یا بالاتر**. هیچ وابستگی (npm install) لازم نیست.

```bash
npm start
```

سپس `http://localhost:3000` را باز کنید.

### نصب تشخیص گفتار روی سرور (یک بار)

```bash
sudo apt install -y build-essential cmake git curl
```

```bash
bash scripts/setup-whisper.sh
```

این اسکریپت whisper.cpp را از گیت‌هاب می‌گیرد و می‌سازد (چند دقیقه) و مدل Whisper را در پوشهٔ `whisper/` دانلود می‌کند. بعد از آن `npm start` را دوباره اجرا کنید؛ باید ببینید «تشخیص گفتار روی سرور: فعال».

**نتیجهٔ آزمایش** (۱۵ جملهٔ نمونه مثل «پراید صد و سی و یک مدل نود و هشت» با دو صدای فارسی، یعنی ۳۰ صدا؛ سرور ۴ هسته‌ای Xeon):

| مدل | حجم فایل | حافظه | زمان هر جمله | خودرو و سال هر دو درست | فقط سال درست |
|---|---|---|---|---|---|
| `large-v3-turbo-q8_0` (پیش‌فرض) | ۸۷۰ MB | ۱٫۱ GB | **۳ ثانیه** | **۱۶ از ۳۰** | ۲۴ از ۳۰ |
| `large-v3-turbo-q5_0` | ۵۵۰ MB | — | ۸ ثانیه | ۱۷ از ۳۰ | ۲۵ از ۳۰ |
| `small-q8_0` | ۲۶۰ MB | ۰٫۵ GB | ۲٫۷ ثانیه | ۱ از ۳۰ | ۱۲ از ۳۰ |

- مدل small برای فارسی قابل استفاده نیست؛ پیش‌فرض، large-v3-turbo-q8_0 است. نسخهٔ q8_0 روی پردازندهٔ آزمایش حدود ۳ برابر سریع‌تر از q5_0 بود (روی پردازنده‌های دیگر نسبت ممکن است فرق کند).
- صداهای آزمایش با موتور تبدیل متن به گفتار (Piper) ساخته شده‌اند که بعضی کلمه‌ها را نامفهوم تلفظ می‌کند (Whisper «سمند» را گاهی «تعدل» شنید). دقت روی صدای واقعی انسان احتمالاً بهتر است ولی اندازه‌گیری نشده.
- خروجی Whisper اغلب آوایی است («پجو» به جای «پژو»، «مودل»، «نوود و هشت»، «چار سد»، «جی الیکس»)؛ تجزیه‌گر برنامه این شکل‌ها را می‌فهمد.
- برای صدای کوتاه‌تر از ۹ ثانیه، پنجرهٔ صوتی کوتاه (`-ac 512`) به کار می‌رود که رمزگذار را حدود ۳ برابر سریع‌تر می‌کند (`WHISPER_AUDIO_CTX=0` = خاموش). گاهی جمله را تکرار می‌کند که برنامه تکرار را حذف می‌کند.

برای مدل دیگر: `bash scripts/setup-whisper.sh small-q8_0`. اگر چند مدل دانلود شده باشد، بهترینِ آن‌ها استفاده می‌شود؛ با `WHISPER_MODEL` می‌توانید مسیر مدل را مشخص کنید.

**اگر huggingface.co از سرور باز نمی‌شود:** فایل مدل (`ggml-large-v3-turbo-q8_0.bin` از [صفحهٔ مدل‌های whisper.cpp](https://huggingface.co/ggerganov/whisper.cpp/tree/main)) را روی کامپیوتر دیگری دانلود کنید و در `whisper/models/` روی سرور بگذارید، یا نشانی دیگری با `WHISPER_MODEL_URL` به اسکریپت بدهید.

چطور کار می‌کند: مرورگر صدا را ضبط می‌کند، پایان جمله را از روی مکث تشخیص می‌دهد، سکوت ابتدا و انتها را می‌بُرد و صدا را به شکل WAV ۱۶ کیلوهرتز به `/api/transcribe` می‌فرستد. سرور whisper را با زبان فارسی و یک «پرامپت» شامل نام خودروهای رایج اجرا می‌کند تا نام‌هایی مثل تیبا، کوییک و ساینا را درست بنویسد (پرامپت بدون عدد است؛ عدد در پرامپت باعث می‌شد Whisper عددهای اشتباه بنویسد). اگر whisper نصب نباشد، برنامه از تشخیص گفتار خود مرورگر (کروم/اج) استفاده می‌کند.

## نکته‌های مهم برای راه‌اندازی

- **سرور باید در ایران باشد.** باما، دیوار و همراه مکانیک درخواست‌های IP خارج از ایران را رد می‌کنند (اتصال قطع می‌شود). روی سرور خارجی، صفحه بالا می‌آید ولی هر سه منبع خطا می‌دهند.
- **میکروفون فقط با HTTPS کار می‌کند** (به‌جز `localhost`). روی سرور، یک دامنه با گواهی SSL لازم است. ساده‌ترین راه، [Caddy](https://caddyserver.com) است که گواهی را خودش می‌گیرد:

  ```
  car.example.ir {
      reverse_proxy localhost:3000
  }
  ```

  با nginx هم می‌شود (`proxy_pass http://127.0.0.1:3000;` و certbot). پشت پراکسی، `TRUST_PROXY=1` بگذارید تا محدودیت درخواست براساس IP واقعی کاربر باشد.
- **حافظه و پردازنده:** هر تبدیل گفتار با مدل پیش‌فرض حدود ۱٫۱ گیگابایت حافظه می‌گیرد؛ سرور دست‌کم ۲ گیگابایت حافظه و ۴ هسته لازم دارد. به‌طور پیش‌فرض در هر لحظه فقط یک تبدیل اجرا می‌شود و بقیه در صف می‌مانند (`WHISPER_CONCURRENCY`). روی پردازندهٔ کندتر یا با هستهٔ کمتر، زمان هر جمله بیشتر از ۳ ثانیه می‌شود.
- **بدون whisper:** اگر تشخیص گفتار روی سرور نصب نباشد، کروم و اج از سرویس گوگل استفاده می‌کنند که ممکن است از ایران در دسترس نباشد؛ در آن صورت کاربر می‌تواند تایپ کند.
- **ساختار سایت‌ها ممکن است عوض شود.** کد هر سایت در یک فایل جداست (`src/sources/`). اگر `npm run diagnose` برای یک سایت خطا داد، فقط همان فایل باید به‌روز شود؛ دو سایت دیگر کار می‌کنند.

### متغیرهای محیطی

| متغیر | پیش‌فرض | توضیح |
|---|---|---|
| `PORT` | `3000` | پورت سرور |
| `EXTRA_PORTS` | در Docker: `80,8080` | پورت‌های اضافه که برنامه روی آن‌ها هم گوش می‌دهد |
| `HOST` | همهٔ نشانی‌ها (IPv4 و IPv6) | نشانی گوش‌دادن، مثلاً `127.0.0.1` فقط برای دسترسی محلی |
| `DEMO` | — | `1` = حالت نمایشی با داده‌های نمونه |
| `RATE_LIMIT` | `20` | حداکثر جستجو در دقیقه برای هر IP |
| `TRUST_PROXY` | — | `1` = خواندن IP کاربر از `X-Forwarded-For` (پشت nginx/Caddy) |
| `WHISPER_MODEL` | بزرگ‌ترین مدل در `whisper/models/` | مسیر فایل مدل |
| `WHISPER_BIN` | `whisper/whisper.cpp/build/bin/whisper-cli` | مسیر برنامهٔ whisper-cli |
| `WHISPER_THREADS` | حداکثر ۴ | تعداد هستهٔ پردازنده برای هر تبدیل |
| `WHISPER_CONCURRENCY` | `1` | تعداد تبدیل هم‌زمان |
| `WHISPER_PROMPT` | نام خودروهای رایج | پرامپت اولیهٔ Whisper (خالی = بدون پرامپت) |
| `WHISPER_MODEL_NAME` | `large-v3-turbo-q8_0` | مدلی که اگر نبود دانلود شود؛ `none` = بدون تشخیص گفتار سرور |
| `WHISPER_MODEL_URL` | huggingface.co | نشانی دانلود مدل (مثلاً از Object Storage لیارا) |
| `WHISPER_MODEL_SHA256` | checksum مدل پیش‌فرض | کنترل سلامت فایل دانلودشده |
| `WHISPER_MIN_MEMORY_MB` | `1400` | کمترین حافظه برای فعال شدن تشخیص گفتار سرور؛ `0` = بدون بررسی |
| `WHISPER_AUTO_DOWNLOAD` | — | `0` = مدل خودکار دانلود نشود؛ `1` = در کانتینر بدون دیسک هم دانلود شود |
| `WHISPER_AUDIO_CTX` | `auto` | پنجرهٔ صوتی: `auto` = ۵۱۲ برای صدای کوتاه، `0` = کامل، یا یک عدد |
| `WHISPER_ARGS` | — | آرگومان‌های اضافه برای whisper-cli |

## API

`POST /api/transcribe` با بدنهٔ WAV (PCM ۱۶ بیتی، تک‌کاناله، ۱۶ کیلوهرتز، حداکثر ۳۰ ثانیه) ← `{ "text": "...", "ms": 2100 }`

`GET /api/price?q=<جملهٔ کاربر>&city=all|1|2,...`

- `query`: برداشت از جمله (`carText`، `year`، `condition`)
- `summary`: برآورد اصلی (`estimate`، `low`، `high`، و سهم هر سایت)
- `newCar`: برآورد صفر کیلومتر؛ `byYear`: برآورد هر سال ساخت؛ `factory`: قیمت‌های کارخانه
- `sources`: نتیجهٔ خام هر سایت (موفق/ناموفق، خطا، مدل پیداشده، آگهی‌ها و فهرست قیمت با لینک)

کدهای شهر دیوار: ۱ تهران، ۲ کرج، ۳ مشهد، ۴ اصفهان، ۵ تبریز، ۶ شیراز، … (پیش‌فرض: این شش شهر).
